# 台美股資產（ClaudeETF）發布專案

這個公開專案只放「給使用者下載與讀取」的檔案，由私密的原始碼專案自動同步，請勿手動修改。

| 路徑 | 用途 |
|---|---|
| Releases `vX.Y.Z` | 使用者版正式版 APK（App 內線上更新、發佈站下載） |
| Release `manual` | 操作說明書 PDF |
| `config/member_policy.json` | 會員政策（已簽章；試用天數、公告、停用名單等） |
| `config/member_pubkey.txt` | 授權驗證公鑰（公開金鑰，非機密） |
| `web/` | 電腦網頁版前端檔案（由發佈站轉送） |

不包含原始碼、伺服器程式、任何 API 金鑰或私鑰。
